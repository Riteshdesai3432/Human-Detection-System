# Project Overview

This project is an AI-based Human Detection, Human Counting, Face Detection, and Emotion Detection System developed using Python, OpenCV, and YOLO.

The system can detect humans in real time using a webcam, count the number of people present, detect faces, and identify facial emotions such as happy, sad, angry, and neutral.

This project demonstrates the use of Computer Vision and Machine Learning concepts in real-time surveillance and monitoring applications.

# How to Run the Project

## Step 1 — Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/Human-Detection-System.git
```

---

## Step 2 — Open Project Folder

```bash
cd Human-Detection-System
```

---

## Step 3 — Create Virtual Environment

```bash
python -m venv .venv
```

---

## Step 4 — Activate Virtual Environment

### Windows

```bash
.\.venv\Scripts\activate
```

### Mac/Linux

```bash
source .venv/bin/activate
```

---

## Step 5 — Install Required Libraries

```bash
pip install -r requirements.txt
```
